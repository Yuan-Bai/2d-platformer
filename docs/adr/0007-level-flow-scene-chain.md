# ADR-0007：M3 内置关卡流转——SceneManager 场景链 + 通关占位画面

M3 决定过关流转在里程碑内落地：`LevelManager`（运行时深模块）持有当前关进度（樱桃计数），终点门触发 `SceneManager` 加载 Build Settings 里的下一场景；最后一关加载「通关」占位画面。M4 的主菜单/音效/打包叠加其上，不推翻此链。

**Considered Options**

- 流转留到 M4 与主菜单一起做：M3 交付更纯，但整条关卡链无法连续试玩，验收标准「4 场景连续可通关」不成立——否决。
- 现在就做：链路从第一天起就是验收目标的一部分，M4 只需把「关卡 0」换成主菜单场景——采纳。

**Consequences**

- Build Settings 场景顺序成为可交付物的一部分（4 关卡 + 通关画面）。
- `LevelManager` 的接口保持窄（见 M3 设计文档第 10 节），M4 接主菜单时不改链路语义。
