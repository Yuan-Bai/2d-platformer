# ADR-0003：分层状态机——状态只做决策，Motor 只算速度

M1 决定角色行为用分层状态机表达（Idle/Run/Jump/Fall），且状态机与运动计算严格分层：状态只依据「落地与否 + 竖直速度方向 + 输入方向」做转换决策，任何速度/位置写入都发生在 `PlayerMotor` 内部。状态机可脱离物理在 EditMode 测试。

**Consequences**

- 表现层接入（M3，ADR-0008）时，动画驱动只读 `PlayerStateId`，不需要感知物理——接缝干净。
- 新增状态（如未来加墙面贴附）只改状态机，不碰 Motor 的手感规则。
