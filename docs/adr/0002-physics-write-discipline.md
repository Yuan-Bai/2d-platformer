# ADR-0002：物理写纪律——PlayerBody 是全项目唯一写 Rigidbody2D.velocity 的地方

M1 定下一条硬纪律：`PlayerBody` 是唯一写 `rb.velocity` 的类；同时重力归零（代码全权施加）、锁定旋转、开启插值。M2 追加两条补充纪律：碰撞摩擦归零（接触求解只负责法向支撑，切向运动完全由代码掌控）、移动平台必须是 kinematic 刚体。

**Consequences**

- 「站在移动平台上走不动」这类 bug 的根因排查（摩擦 0.4 + velocityThreshold 钉住切向速度）被这条纪律直接定位到接触求解器与代码写速的边界。
- 速度补偿方案（ADR-0005）依赖这条纪律成立：角色速度与携带速度在同一行代码里合并写入，不存在第二个写入者互相覆盖。

> 补录于 M3 阶段 0：本决策在 M1/M2 已生效于代码（`PlayerBody.cs` 注释多处引用 ADR-0002），此前未落盘。
