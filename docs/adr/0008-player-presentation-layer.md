# ADR-0008：玩家表现层只读状态 + 碰撞盒对齐 32px 视觉（M3）

M3 决定：(1) Foxy 动画由 `PlayerStateId` 驱动，表现层组件只读状态机输出、不回写任何手感数据；fall 状态复用 jump 第 2 帧（素材无独立下落动画）。(2) 玩家碰撞盒从 M1/M2 的 1×1 占位方块改为约 0.5×1.6，对齐 Foxy 32px（PPU 16 → 2 单位高）的视觉身高，视觉略大于碰撞盒保证宽容。

**Considered Options**

- 保持 1×1 盒、视觉缩到盒内：美术被裁，Foxy 像素细节损失——否决。
- 对齐视觉改盒：所有关卡间隙度量以新盒为基准重算（本里程碑关卡全新建，无历史包袱），手感规则在 Motor 里与盒无关（地面探测在适配层）——采纳；回归测试 19+6 全绿作为手感无回归的兜底。

**Consequences**

- 关卡生成器的可通行性计算（跳高 2.52m/满速跨度 ≈5m 等，见设计文档第 2 节）必须按新盒尺寸校核天花板净高与落地容差。
- 碰撞盒终值（宽/高）以实现期实测为准，允许 ±0.1 内微调，最终值回填本 ADR。
