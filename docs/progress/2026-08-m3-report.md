# M3 阶段报告：狐跃林间（Foxy's Forest）

> 2026-08 · 覆盖：架构会话（需求锚定）→ 阶段 0（文档）→ 阶段 1（基础设施）→ 阶段 2（生成器）→ 阶段 3（关卡数据）→ 阶段 3.5（手工搭关工具链）。

## 1. 做了什么

### 阶段 0：需求锚定与设计落盘
- grilling 三轮锚定 15 项决策：混合分工（AI 生成初版 + 用户试玩微调）、Foxy 外观进 M3、终点门 + 可选樱桃、教学关 + 3 正式关、M3 内置关卡流转、世界路牌 + 中文 UI 提示、统一森林主题、机制递进分配、樱桃 HUD 方案、正式命名**「狐跃林间 / Foxy's Forest」**、休闲难度基调；后续追加决议：关卡数据改单文件 JSON、Celeste 式动作扩展（冲刺/滑墙/蹬墙跳/二段跳）定于 **M4 后开 M5**（2D 沙盒为 3D 项目打基础）。
- 交付：`CONTEXT.md`（术语表）、ADR-0001~0008（前 5 份为补录——此前只存在于代码注释引用；新增 3 份为 M3 决策）、`docs/design/m3-levels.md`（13 节设计文档，含可通行性度量基准与四关节拍表）。

### 阶段 1：基础设施（运行时组件）
- 玩家表现层 `PlayerVisuals`（状态机驱动帧循环，fall 复用 jump 末帧）；`BumperVisual` 弹簧压缩动画（动画只在子物体，防缩放触发器）。
- 关卡流程：`LevelManager`（樱桃计数 + 冻结输入 → 统计 → 加载下一场景，时间戳计时）、`LevelExit`、`Collectible`、`TutorialTrigger`、`GameClearScreen`。
- UI：`CherryHud`、`HintBar`（淡入→停留→淡出）；文本选型 **legacy Text**（TMP 默认字体不含 CJK 字形，M4 升级 TMP + CJK SDF）。
- `ParallaxBackground` 两层视差（池化平铺、零逐帧分配）。
- 修复：`InputReader` 新增 `OnDisable` 归零（过关冻结不残留按键）；`Bumper` 新增 `Bounced` 事件。
- Editor：`SunnyLandArtTools`（美术 PPU16/Point 规范化；切片归用户，`Build Tiles From Existing Slices` 从用户切片生成 Tile 资产）。

### 阶段 2：关卡生成器
- `LevelData`（JSON DTO + `TryParse`，处理 JsonUtility 不跑构造函数的问题）；`LevelValidator`（纯 C# 结构/几何校验）。
- `LevelBuilder`：JSON → 场景全自动装配（tilemap 草顶/纯岩自动选块 + Composite 碰撞、五机关、樱桃/路牌/门、玩家新盒 0.5×1.6 + Foxy 动画、VCam + 独立矩形相机边界、视差、HUD、LevelManager 关卡链、Build Settings 排序）。
- 测试：EditMode `LevelDataTests` 15 个、PlayMode `M3LevelFlowTests` 2 个，全部通过。

### 阶段 3：关卡数据
- 4 份关卡 JSON（教学「第一步」64×16、关1「林地小径」76×18、关2「云上栈道」80×20、关3「棘林深处」88×22），由本地脚本**段拼接 + 长度断言 + 镜像校验器**程序化生成，避免手工数长串出错。

### 阶段 3.5：手工搭关工具链（响应用户两个问题）
- `LevelKit`：共享工厂（单一事实源）——JSON 生成器与预制体共用同一批组件装配。
- `Build Prefabs`：生成 `Assets/Prefabs/` 9 个乐高块（Player/Bumper/MovingPlatform/Spikes/Checkpoint/Cherry/Door/Sign/OneWayPlatform）。
- `New Level Scaffold`：空场景脚手架（相机/VCam/边界/背景/HUD/LevelManager/空 tilemap 含碰撞）；手工流程 = Tile Palette 刷图 → 拖预制体 → Inspector 配两个引用 → Build Settings。
- `LevelBuilder` 重构为消费 LevelKit 工厂。

## 3. 遇到的问题（根因 → 解法）

| 问题 | 根因 | 解法 |
|---|---|---|
| `Tile.ColliderType` 编译错 | 常量 `const int Tile` 遮蔽类型名 | 改名 `TileSize` |
| `TextureImporter.spritesheet` 弃用警告 | 2022.2+ 移除该 API | `ISpriteEditorDataProvider` + `Unity.2D.Sprite.Editor` 程序集引用 |
| `unsafe` 变量名编译错 | C# 保留关键字 | 改名 `spawnUnsafe` |
| tileset 尺寸误读（量成 144×112） | `Get-Content -TotalCount` 按记录截断损坏二进制字节流 | 改 `Format-Hex`；切片归用户（25×23 实际正确），工具改为从既有切片生成 Tile 资产 |
| 相机 NaN | `CinemachineConfiner2D` 用 tilemap `CompositeCollider2D` 当边界：场景加载瞬间复合几何未生成 | 独立矩形 `PolygonCollider2D` 相机边界（也是设计文档 §4 原意） |
| 校验几何规则两版推倒 | 「空坑宽度」与「每列必须有底」规则矛盾；下坡误判为坑 | 收敛为绑定设计约定：坑底全铺尖刺 → **尖刺连续段宽 = 坑宽**；上台高度/可达性不做（诚实边界：装饰高墙 vs 必经台阶无法区分），试玩兜底 |
| 过关后玩家仍奔跑 | 仅禁用 InputReader 会残留最后按键状态 | `InputReader.OnDisable` 归零（禁用 = 中性输入） |
| 弹簧动画覆盖基础缩放 | BumperVisual 每帧重写 localScale 未捕获基准 | 捕获 `_baseScale` 在其上叠加压缩 |
| 长行地图手工构造易错 | 人工数 64~88 字符 | PowerShell 段拼接 + 长度断言 + 镜像 LevelValidator 校验后才写文件 |
