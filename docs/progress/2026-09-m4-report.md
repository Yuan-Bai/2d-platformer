# M4 阶段报告：收尾（常驻架构 / 菜单 / 音频 / 打包）

## 目标回顾

M4 蓝图（`docs/design/m4-polish.md`）：跨场景常驻重构（M4a）、主菜单与暂停（M4b）、音频（M4c）、打包收尾（M4d）。

## 决策记录

延续 M3 锚定的 grilling 决策：

- **常驻架构**：Bootstrap 场景常驻 + 关卡 Additive 加载（ADR-0009，取代 ADR-0007 场景链）
- **菜单**：开始/退出/音量滑条；与 Bootstrap 合并为 00-Bootstrap 场景
- **暂停**：Esc + 面板（继续/音量/回主菜单），timeScale=0
- **通关画面**：05-GameClear 场景退役 → 常驻面板化
- **音频**：音乐菜单/关卡/通关三曲；SFX 选 Kenney CC0
- **无持久存档**：用户确认不添加通关进度记录（死亡回重生点、重开从第一关）
- **打包**：1280×720 窗口 + Alt+Enter 全屏、Windows x64 release、icon=Foxy idle 第一帧

## 实施内容

### M4a 跨场景常驻架构

- `GameFlowController`：常驻单例 + `FlowState{Menu,Playing,LevelClear,GameClear}`；Additive 异步加载/卸载关卡；玩家出生点重置、相机重绑、HUD 显隐
- 关卡场景瘦身为纯内容：`SpawnPoint` / `LevelConfig`（本关樱桃数）/ `CameraBoundsAnchor`
- `LevelManager` 退役，机关直接对接 `GameFlowController.Instance`
- 测试：切关/回菜单/末关语义（PlayMode 19）

### M4b 菜单与暂停

- 主菜单视觉（森林背景/描边标题/狐狸立绘/按钮/音量滑条）
- 暂停菜单（Esc）：继续/音量/回主菜单
- `VolumeSlider`：PlayerPrefs 持久化 + 静态事件广播（跨面板同步）
- UI 交互修复：Bootstrap 场景补 `EventSystem` + `GraphicRaycaster`（运行时兜底）
- 测试：暂停状态机与 timeScale 恢复（PlayMode 19）

### M4c 音频

- `AudioManager`：音乐循环 + 随 FlowState 自动切曲 + 切场景不中断；SFX 语义方法（跳跃/樱桃/弹簧/死亡/门/点击）
- 音效：Kenney CC0（Retro Sounds / Impact / Interface 三包），许可文件入库
- 修复：空关卡列表直通 GameClear 的越界守卫
- 测试：切曲逻辑 + 音量事件流（PlayMode 21）

### M4d 打包

- icon：Foxy idle 第一帧 → 16~256 多尺寸 + PlayerSettings 图标
- 窗口：1280×720、Windowed、resizable、Alt+Enter 全屏开关
- Windows x64 release 打包（场景列表排除测试夹具 TestLevelA/B）

## 测试

- EditMode 43/43 + PlayMode 21/21 全绿
- 全流程验收（execute_code）：菜单 → 4 关连续 → 通关 → 回菜单，玩家全程不重建

## 遗留确认点

- 主菜单在 4:3 老显示器/窗口缩小时布局未优化（固定 1280×720 设计）
- 视差背景左右边缘覆盖瑕疵（M3 遗留，非回归）
- 无持久存档（按设计）
